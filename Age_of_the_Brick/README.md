# Age of the Brick

Real-time strategy game built with **Unity 6** (URP, Input System, AI Navigation, uGUI).

## Open the project

1. Install Unity **6000.0.58f1** (or matching 6000.0.x from `ProjectSettings/ProjectVersion.txt`)
2. Open this folder as a Unity project

## Status

Active prototype: selection, commands, gathering, building placement/production, era-based stats.
